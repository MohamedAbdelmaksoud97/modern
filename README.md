# منصة مودرن للاستشارات الهندسية

منصة مكتب هندسي تشمل الموقع التعريفي وسابقة الأعمال وإدارة المشروعات والعملاء والمالية والإشراف الميداني وبوابة العميل. العربية هي اللغة الافتراضية. تتوفر الإنجليزية والوضعان الفاتح والداكن.

للتشغيل المحلي، اضبط اتصال Postgres في `.env.local` حسب `.env.example`، ثم نفّذ:

```sh
npm ci
npm run db:migrate
npm run dev
```

الموقع على [localhost:3000](http://localhost:3000)، وتسجيل الدخول على [/login](http://localhost:3000/login). في قاعدة بيانات جديدة، تُنشأ بيانات المدير الأولية في `.local/bootstrap.json` ويُطلب منه تغيير كلمة المرور عند الدخول.

راجع [دليل النشر](docs/DEPLOYMENT.md) لإعداد الخادم وHTTPS، و[دليل واتساب](docs/WAHA.md) لإعداد WAHA وربط هاتف المكتب. [نتائج التحقق](docs/VERIFICATION.md) تسجل الاختبارات المنفذة وما يتطلب بنية الإنتاج.

لتجربة دورة المشروع على SQLite ببيانات محلية، شغّل `npm run test:workflow:sqlite`. التفاصيل في [تقرير تجربة التشغيل](docs/SQLITE-WORKFLOW-VERIFICATION.md).
